## FAQ

### Is VideoPatch free to use?

Yes, VideoPatch is completely free and open-source. You can download, inspect, and use it without any cost.

### Which video editors does VideoPatch support?

VideoPatch supports CapCut, DaVinci Resolve, Filmora, VideoPad, HitFilm, and Movavi on Windows.

### Do I need to uninstall my video editor first?

No, VideoPatch works on top of your existing installation. Simply run the patcher with your editor closed and it will modify the necessary files.

### What does the extraction password do?

The ZIP archive is password-protected with 'videopatch' to prevent automatic scanning by certain security tools. This is standard practice for legitimate open-source distribution.

### Will VideoPatch work on macOS or Linux?

No, VideoPatch is designed exclusively for Windows desktop systems. macOS and Linux are not currently supported.

### Will updates to my video editor undo the patch?

Yes, major updates from the editor's developer may revert patched files. Simply re-run VideoPatch after updating to re-apply the changes.

### Is it safe to use VideoPatch?

VideoPatch modifies local application files only and does not connect to external servers. Always download from the official repository to ensure file integrity.

### Can I patch multiple editors at the same time?

Yes, the installer lets you select one or more editors to patch in a single session. Each patched application is handled independently.

### What should I do if a patch fails?

Ensure the target editor is fully closed, run videopatch.exe as administrator, and check that the correct version of the editor is installed. Consult the FAQ or open an issue on GitHub if the problem persists.
